# Heptabase Journal (日誌) 網頁純享版

這是一個專門仿照 **Heptabase** 經典「**日誌 (Journal)**」功能所打造的輕量化獨立 Web 應用程式。

---

## 🌟 核心特色

1. **經典雙視圖切換**：
   - **連續流視圖 (Stream)**：垂直時間軸，如同 Heptabase 原生體驗，可連續瀏覽各日筆記。
   - **單日聚焦視圖 (Focus)**：專注於當日筆記撰寫。

2. **迷你日曆與快速跳轉**：
   - 左側內建月曆，**有寫日誌的日期會自動顯示藍色小圓點提示**。
   - 點擊日曆任何一天即可立即定位與編輯該日日誌。
   - 提供「今天」、「昨天」、「明天」快速按鈕。

3. **強大且流暢的區塊編輯 (Slash Command)**：
   - 在任何位置輸入 `/` 即可呼叫快捷選單：
     - **標題 1 / 2 / 3 (H1, H2, H3)**
     - **待辦清單 (To-do)**：可點選勾選方塊，附帶刪除線動畫
     - **符號 / 數字清單 (Bullet / Numbered List)**
     - **重點備註方塊 (Callout Block)**
     - **原子卡片 (Atomic Card)**：在日誌中嵌入專屬知識卡片
     - **引用 (Quote)**、**分隔線 (Divider)**、**程式碼區塊 (Code)**
   - 支援 Markdown 常用語法快捷觸發（如輸入 `# `、`## `、`- `、`[] `、`> ` 後按空白鍵自動轉換）。

4. **浮動選取工具列 (Selection Toolbar)**：
   - 選取文字時自動彈出快捷工具列（粗體、斜體、刪除線、螢光筆高亮）。

5. **右側卡片庫 (Card Library)**：
   - 收集在日誌中提及或新增的原子卡片，點選可直接回溯關聯日期。

6. **全離線與安全備份**：
   - **即時自動儲存 (Auto-save)**：寫入瀏覽器 LocalStorage，無需伺服器或連網，開啟即用。
   - **單日 Markdown 匯出**：點選日誌右上角下載圖示，即可將該日筆記匯出為標準 `.md` 檔案。
   - **完整 JSON 備份與匯入**：左下角一鍵匯出全量備份，更換電腦或瀏覽器隨時還原。

7. **深色 / 淺色主題**：
   - 支援 Heptabase 招牌的質感深色暗夜模式與明亮淺色模式，右上角一鍵切換。

---

## 🚀 如何使用？

1. **直接開啟**：
   - 直接用滑鼠連點兩下資料夾內的 `index.html`，即可在任何瀏覽器（Chrome、Edge、Firefox 等）中秒速開啟並開始使用。
2. **無需安裝任何環境**：
   - 本專案採用原生現代前端技術，不需要安裝 Node.js、npm 或 Python，無任何外部相依性，保證 100% 離線可用。
